# ３年2組 恒常性メモリアル 4月〜6月編 β 1.0

15人が登場する、4月8日から6月22日までのテストプレイ版です。ユーザーのご希望をもとに、V4の全体設計とエモ版の人物仕様を参照し、３年２組の物語を新たに組み立てました。秋の短いエピローグで終わります。

## 起動

同じフォルダの「本編β版を起動.command」を実行し、ブラウザで `http://127.0.0.1:8872/` を開きます。すでにサーバーが起動中ならURLの再読み込みで遊べます。Python 3が必要です。

**この本編は四月βとは別のセーブ領域です。最初から始まります。** 四月βの記録はブラウザに残りますが、この本編への引き継ぎはありません。JSON保存も本編用です。

## 日々の進行

- 平日：朝の会話・行事があれば読み、放課後の行動を1つ選んで下校します。平日の夜パートはありません。
- 土日：昼の行動・下校の後、夜に次の週末へ出かける約束を持ちかけられます。ねむは午後だけ。約束の相手や場所の個別会話は初回のみ表示し、以降のお出かけは短い記録で進みます。
- 下校：その人物の新しい会話を順に表示。読み切った後は「仲良く帰った」と短く記録します。相手の希望に合わない人物とは、3回目は友情の会話になります。
- 「次の週末や行事まで進む」で日付をまとめて進められます。重要行事、初めての出会い、予定済みの約束、中間考査は飛ばしません。飛ばした日の能力上昇はありません。

## 行事

4月17日オリエンテーション、5月8日体育祭、5月15日山登り、5月29日遊園地、6月5日湖上学習、6月21日文化祭、6月22日終幕。中間考査は5月20日です。V4の設計と３年２組案で体育祭の日付に違いがあるため、体育祭を５月、文化祭を６月に配置しました。各行事は短い共通イベントです。

## 成長と結末

能力は「学力・理科・体力・料理・芸術・気くばり」の6つ。放課後の行動で増えます。ストレスが80以上では能力の伸びが小さくなります。休むとストレスが下がります。

15人それぞれに2〜3項目の必要能力があり、会った後の手帳に目安を表示します。個別の結末には、①モチーフの推理成功、②親しさ12以上、③休日のお出かけ1回以上、④その人の必要能力を満たすことが必要です。条件を満たさなくてもクラス全員の結末に進みます。

主人公の性別と、親しくなりたい相手の希望は途中で変更できます。全員と交流できますが、親しい会話・休日の誘い・個別の結末は希望に従います。主人公の性別によるセリフの差し替えはありません。

## 検証と範囲

`node tests/full.test.cjs`：15人すべての個別結末へ4〜6月を通して進行、７行事、平日の夜なし、台詞・選択肢の再表示なし、手帳・約束・セーブ復元を確認。`node tests/ui-smoke.test.cjs`：画面の操作処理を模擬DOMで最初からここルートの結末まで検査。ブラウザの実画面や各端末での最終表示・音量は未検証です。

V4のシステム設計・行事構成とエモの人物設定は参照し、V4の台本・セリフは流用していません。V4の `game-v4.json` との台詞・選択肢の12文字以上の完全一致は0件です。文面の意味まで自動的に保証する検査ではありません。

会話画面は上半身を中心に表示し、発話者はカラーで手前、それ以外は少し小さくグレーにします。人数に応じて表示倍率を変えています。

新規背景4枚：遊園地・山道・湖上・学園祭。生成記録は `assets/backgrounds/events_manifest.json`。全身立ち絵15人×6表情は従来の素材を使用。行事画面は通常の立ち絵を使用し、衣装・覚醒差分の新規制作は行っていません。

BGMは既存ゲームから許可されたローカル試遊用素材に加え、takai / [音楽の卵](https://ontama-m.com/) の「朝の支度」「黄昏時」を使用。新たな音源取得は必要としませんでした。フリー音源の詳細は `BGM_CREDITS.md` と `music_manifest.json`。公開する場合は既存曲の権利と利用条件の再確認が必要です。
